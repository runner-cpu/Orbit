# 改进方案：从「一篇文章配一个球」到「一台可以自己操作的仪器」

依据：`design-taste-frontend` 与 `design` 两个 skill 的规则，加上对本页的逐项像素与文本测量。

> **范围修正（团队确认后）**
>
> 1. **资料来源在网页中只做简单介绍。** 数据来源、算法细节、已知局限等完整说明由团队另出说明文档承载；网页上保留「一行来源 + 可展开折叠块」即可，不占正文阅读动线。
> 2. **探索模式不做。** 叙事读完后的自由筛选不纳入本次范围。

---

## 一、诊断（全部为实测值，可复算）

### 1.1 文字量

| 指标 | 实测 | 每步平均 |
|:---|:---|:---|
| 正文字符（不含方法页） | 5,574 | 232 字 |
| 正文段落 `<p>` | 73 | 3.0 段 |
| 「口径」块 `cite` | 18 | 0.75 个 |
| 「结论」块 `finding` | 14 | 0.58 个 |

合计 **每步 232 字 + 3 段 + 1.3 个说明块**。`design-taste-frontend` 第 4.9 节给的上限是「短标题（≤ 8 词）+ 短副段（≤ 25 词）+ 一个视觉资产或一个 CTA」。按 25 词≈40 中文字折算，现在**超了约 5 倍**。

### 1.2 滚动长度

| 章 | pinRatio 之和 |
|:---|:---|
| 一 | 6.7 屏 |
| 二 | 6.0 屏 |
| 三 | 5.1 屏 |
| 四 | 5.1 屏 |
| 五 | 8.2 屏 |
| **合计** | **31.1 屏** |

### 1.3 右栏单调的结构性原因

21 个场景的自由度只有三个：

- 方位角 −0.35 至 1.62 rad（跨度 113°）
- 仰角 0.02 至 0.62
- 视距 2.35 至 8.40 倍地球半径

`SceneState` 的 13 个字段（`pose / categoryMix / dim / emphasize / referenceLayers / spin / opacity / catalogVisible / yearMax / debrisVisible / debrisOpacity / debrisFilter / horizon`）**没有一个能承载坐标轴、刻度或标签**。接口只能表达「哪些点可见、机位在哪」，无法表达「这里有一条时间轴」。

结论：不是场景写得不够多，是**接口没有给仪器留位置**。

### 1.4 版式重复

24 步共用同一副骨架：`h2 → p → p → readouts → finding → cite`。18 种模板差异只是同一句话的不同断句。

### 1.5 破折号

| 字符 | 数量 |
|:---|:---|
| `—` U+2014 | 56 处 |
| `–` U+2013 | 23 处 |

`design-taste-frontend` 第 9.G 节把 `—` 列为**完全禁止**（headlines、eyebrows、body、quotes、captions、alt text 全部），`–` 用作分隔符同样禁止。日期范围与数字范围一律用普通连字符 `-`。

## 二、右栏改造：每章一台专属仪器

### 2.1 设计原则

球**保留**，因为它是全页唯一能让「轨道」这个概念落地的东西，删掉会变成纯图表页。但球从「唯一主角」降为「底座」：缩小、偏移，给仪器让出位置。

仪器用 **DOM + SVG 实现，不用 WebGL**。理由：刻度、标签、hover 命中检测是 DOM 的强项；在 canvas 里做这些要自己写命中检测与文字排版，得不偿失。球继续走 WebGL。

两者叠在同一个 `#stage` 容器里，球在底层，仪器在上层。

### 2.2 五台仪器

| 章 | 仪器 | 交互 | 球上发生什么 |
|:---|:---|:---|:---|
| 一 | **高度剖面尺**：竖排 0-2000 km，每层一条密度条 | 点选一层 | 只留那一层，其余压暗到 0.1 |
| 二 | **年份轴**：横排 1957-2026，轴上画累积曲线 | 拖动游标 | 点按发射年逐个出现，轴上同步显示当年数量 |
| 三 | **近地点直方图**：50 km 一档的柱状图 | 悬停某档 | 只留那一档的碎片，柱本身高亮 |
| 四 | **双轨道面转盘**：两个同心环 + 交线 | 拖动旋转 | 两个碎片云跟着转，交线角度实时显示 |
| 五 | **时间滑块 + 层存活条**：0-200 年 | 拖动滑块 | 低层碎片先消失，每层存活比例同步更新 |

每台仪器都满足：**有坐标轴、有刻度、有单位、能被鼠标直接操作**。这是现在完全没有的东西。

### 2.3 接口改动

`SceneState` 增加一个字段：

```ts
/** 当前场景要挂哪台仪器。null = 不挂 */
instrument: InstrumentId | null;
```

新增 `src/core/instrument.ts` 负责：
- 仪器的挂载 / 卸载 / 过渡
- 把用户的交互（点选、拖动、悬停）翻译成回调
- 回调再驱动 `PointLayer` 的 uniform

关键约束：**仪器是叙事的一部分，不是附加物**。拖动年份轴必须真的改变球上的点，而不是只在图上画个游标。这一点现在做不到，因为场景层没有任何通道接收「用户拖到了 1980 年」这个事件。

## 三、正文改造：从「文章」改成「图表注」

### 3.1 硬上限

每步正文：

- 一个 `<h2>`（≤ 12 字）
- 一句 lead（≤ 40 字）
- 一个数据点标注（≤ 20 字）

**合计 ≤ 72 字**，是现在的 31%。

超出这个预算的内容，按下面的规则处理。

### 3.2 三类内容的去处

| 现在的内容 | 去处 |
|:---|:---|
| 「口径」说明（18 处） | 收进 `<details>` 折叠块，summary 只写「依据」两字 |
| 「结论」块（14 处） | 只保留 5 处（每章一个），其余删掉，让数据自己说 |
| 「小结」步骤 | 全部删除，改成章节末尾一行式过渡 |

「小结」这一步现在是纯复述。第一章的小结复述三个数字，第二章的小结复述增长曲线，第五章的小结复述机制。读者刚看完，不需要再看一遍。

**关于资料来源**：网页只保留一行来源（CelesTrak + 数据历元）与可展开的折叠块。完整的来源清单、算法推导、已知局限与复算步骤由团队另出的说明文档承载，不再逐条铺在页面上。折叠块里的内容保留，是为了让评审能在页面上直接核对，而不是为了讲给读者听。

### 3.3 删除清单

| 文件 | 删除 |
|:---|:---|
| `chapter1.ts` | `summary` 步 |
| `chapter2.ts` | `growth-summary` 步 |
| `chapter3.ts` | `fy-verdict` 步 |
| `chapter4.ts` | `impact-verdict` 步 |
| `chapter5.ts` | `decay-close` 步 |

24 步 → 19 步。每章末尾用一行「下一节」替代。

### 3.4 破折号清理

79 处全部替换。规则：

- `——` → 逗号或句号（拆成两句）
- `–`（数字/日期范围）→ `-`
- `–`（作分隔符）→ 逗号

## 四、新增交互：让读者能问自己的问题

### 4.1 点选对象

点球上任意一个点 → 弹出读数卡：对象名、类别、近地点、倾角、发射年。

技术：射线拾取（`THREE.Raycaster`）对 15,934 个点做命中检测。为了性能，用一个独立的、只含位置的简化几何体做拾取，不碰渲染用的着色器。

### 4.2 类别开关

顶栏加 4 个 chip（工作中的载荷 / 失效载荷 / 火箭残骸 / 碎片），点击切换显示。复用已有的 `emphasizeCategories`，不新增着色器逻辑。

### 4.3 探索模式（本次不做）

叙事读完后解锁自由筛选。团队决定暂不纳入范围，这里只记录原始设想，不再作为交付项。

## 六、验收标准

改完之后，以下每一条都必须能勾上：

- [ ] 右栏任意时刻至少有一台带刻度与标签的仪器，且能被鼠标直接操作
- [ ] 每步正文 ≤ 72 字
- [ ] 每步只有 1 个说明块（折叠）
- [ ] 全页 `—` 与 `–` 数量为 **0**
- [ ] 滚动总长 ≤ 20 屏
- [ ] 点球上任意一点能弹出该对象的读数
- [ ] `npm run verify` 仍然 75 项全过（数据层不动）
- [ ] 键盘可操作：仪器可用方向键微调，点选对象可用 Tab 遍历
- [ ] `prefers-reduced-motion` 下仪器不播过渡动画

## 七、明确不做的

- **不换技术栈。** 现在是 Vite + 原生 DOM + three.js，跑得很好（线上 99.8 fps）。`design-taste-frontend` 默认推荐 React + Tailwind，但第 2.B 节明确说了「aesthetic, not a system」的场景就用原生 CSS。本页属于这一类。
- **不引入组件库。** 仪器是定制图形，没有哪个库能直接用。
- **不改数据层。** `build-history.mjs`、`verify-data.mjs`、点云格式全部不动，只改渲染与文案。
- **不加浅色主题。** 深空冷色是锁定风格，`design-taste-frontend` 第 4.11 节允许单主题。
- **不做探索模式。** 见 4.3。
- **不在网页上展开方法细节。** 网页只留一行来源与折叠块，完整说明另出文档。
