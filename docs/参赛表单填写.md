## 3. 作品简介（主版本约 500 字）

《轨道之上：一片正在增厚的碎片带》是一件以真实轨道编目数据为证据的交互式科学传播长页。作品把近地轨道上 15,934 个可定位编目对象逐一解算、绘制成可旋转的三维点云，并用 2,676 个真实碎片，把「凯斯勒综合征」从一个抽象名词变成一条可以亲眼查看、亲手筛选的碎片带。

全片由五章滚动叙事串起：从「头顶有多少东西」「数量为何不是线性增长」，到 2007 年风云一号C 解体、2009 年宇宙 2251 与铱星 33 相撞，最后落到「不同高度层的清除速度相差两个数量级以上」。读者可以拖动时间轴看 1957→2026 的逐年变化，用中线切开画面做时间对照，进入八步讲解模式听一条完整的论证线，也可以在「自由探索」里按类别、近地点高度、发射年份、碎片群与时间自行筛选，拖拽旋转、滚轮缩放观察任意一层。

创新点在四处：一是时间轴锚定固定数据历元（2026-10-13），同一输入永远得到同一画面，结论可复现、可当场核验；二是全部 18,610 条轨道根数在构建期用 SGP4 解算为二进制点云，运行期只改着色器 uniform，零后端、不依赖任何外部服务，断网可完整运行；三是把「编目在轨 35,328 个、能定位 15,934 个」的差值本身做成结论，明确告诉观众画面偏乐观；四是把方法、口径与 79 项数据断言放进页面，任何一个读数都能由脚本从原始数据复算。

应用价值上，作品适合科技馆展项、中学地理与物理课堂、线上科学传播，也可作为「如何用公开数据讲清一个科学问题」的教学案例。

### 精简版（约 150 字，若表单限 300 字内用）

作品以 CelesTrak 公开编目为数据源，把 15,934 个可定位在轨目标与 2,676 个真实碎片绘制成可旋转的三维点云，用五章滚动叙事回答「近地轨道正在变成什么样」。观众可拖时间轴、切开画面做时间对照、进入八步讲解，或在自由探索中按类别、高度、年份、碎片群筛选。全部轨道在构建期由 SGP4 解算，运行期零后端、不访问任何外部服务，断网可运行；数据历元固定，结论可复现。适合科技馆、课堂与线上科普。

## 4. 创意来源（约 520 字）

选题起点是一个反差：公众印象里的太空是空的，但公开编目里，地球周围已经有 35,328 个在轨目标，其中 16,801 个还在工作，其余大部分是失效载荷、火箭残骸和碎片。更反直觉的是，能算出位置的只有 15,934 个——公开轨道根数只维护还有人在用的对象。这个「画不出来的一半」本身就是作品想讲的第一个事实。

第二个起点是 2007 年 1 月 11 日。风云一号C 在 865 公里高度被动能拦截器击毁，一次试验留下近两千个可定位碎片、编目里属于该事件的有三千多个；两年后，宇宙 2251 与铱星 33 又在 790 公里高度意外相撞。两次事件、两种成因，后果却落在同一条高度带上。把这两次事件与「大气阻力随高度急剧失效」的物理事实放在一起，它们能构成一条完整的因果链：碎片被撒进一个很宽的壳，低处的几年内被清掉，高处的几百年也掉不下来。

第三个起点是表达方式。常见的太空垃圾科普要么是网图拼贴，要么是煽情文案，读者看完只记住「很可怕」。我们想做一件相反的事：先不给结论，先给可操作的证据。于是有了可拖动的年份轴、可切开的时间对照、可逐层点选的高度剖面，以及一条能自己筛的自由探索面板。观众不是被告知「高空碎片不会消失」，而是自己把 800 公里以上那一层点开，看到清除率停在 0.2%。

技术上的动机则来自评审场景：答辩现场网络不可靠、设备不可控、时间只有几分钟。因此作品必须离线可运行、结果可复现，并且能在八步之内把论证讲完——这三点直接决定了数据历元固定、构建期解算、讲解模式这三个设计。

## 5. 运行环境（约 270 字）

本作品为纯静态 Web 应用，无需安装客户端，也不需要后端服务或数据库。

- **硬件**：近五年内的常见笔记本、台式机或手机即可；集成显卡可运行，页面会在帧率持续偏低时自动降低像素比与叠加亮度。建议分辨率不低于 1280×720；390 像素宽的手机屏幕已做适配。
- **系统平台**：Windows / macOS / Linux 均可。浏览器需支持 WebGL 2 与 ES2020，推荐 Chrome / Edge 最新版；答辩演示建议使用 Chrome，并预留独立显卡或较新的集成显卡。
- **运行方式**：所有数据随包分发，运行时不访问任何外部服务，断网可完整运行。线上版直接访问 https://runner-cpu.github.io/Orbit/；离线版将 `dist/` 放入任意静态文件服务器即可（如 `npx vite preview` 或 `python -m http.server`）。不能直接双击 `index.html`，浏览器同源策略会拦截 `data/` 读取。
- **构建环境（仅开发需要）**：Node.js 20+，`npm ci && npm run build`；构建前 `npm run verify` 会核对 79 项数据断言。
- **体积**：构建产物约 2.1 MB，其中数据约 1.3 MB（未压缩）；首屏 JS/CSS/数据 gzip 后约 577 KB，编目名称表另 53 KB 按需加载。
