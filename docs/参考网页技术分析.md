# 参考视频里的网页：构造分析与可借鉴项

对用户提供的参考视频（`docs/ref-video/`，1280×580，共 16 帧均匀采样 + 14 帧转场采样）
做了逐帧像素测量。下面是量出来的结论，不是观感描述。

测量脚本与帧文件都在 `docs/ref-video/`，任何人可以复算。

---

## 一、版面：三栏，比例约 14 : 72 : 14

| 区域 | 横向范围 | 内容 |
|:---|:---|:---|
| 左留白 | x 0–176 | 全黑，亮度均值 0.0 |
| 叙事栏 | x 177–1096 | 文字与图表，亮度均值 26–61（随帧变化） |
| 分隔线 | x 1097–1103 | 5 px 竖线，亮度约 220 |
| 右留白 | x 1104–1280 | 全黑，亮度均值 0.0 |

两侧各留约 14% 的纯黑边距，中间 72% 承载全部内容。这是印刷式的做法：
把内容压到中间，两侧用黑把视线框住，而不是把文字铺满整屏。

顶部有一条横贯叙事栏的亮带（y 0–48，覆盖 x 177–1103，宽 927 px）。
带内颜色从 #fddecd（浅暖粉）渐变到 #fffcfb（近白），下边缘在 y 47 骤然转黑。
这条带是整页唯一的暖色区域，与下方冷色内容形成强对比。

底部没有常驻字幕条：底部 50 行的亮像素只有 117 个（8 个/行），
即只有零星几个字的刻度，不是字幕。此前「底部字幕条」的判断不成立。

## 二、时间结构：内容在推进，容器不动

对左中栏（x 190–1090）做帧间差分，与首帧相比：

| 帧 | 差异均值 | 变化像素 |
|:---|:---|:---|
| f00（0.0 s） | 基准 | — |
| f02（2.2 s） | 4.96 | 10,921 |
| f05（5.4 s） | 13.98 | 34,865 |
| f08（8.7 s） | 13.83 | 34,240 |
| f12（13.0 s） | 15.28 | 36,693 |
| f15（16.3 s） | 35.34 | 84,386 |

内容区在持续变化（最后两秒变化量翻倍以上），而分隔线与两侧留白在所有帧
完全不变。也就是说：**版面骨架是固定的，只有叙事栏在滚动**，
不是整页滚动。

## 三、竖线的真实作用：版式分割，不是进度条

x 1097–1103 这 5 px 竖线在全部 16 帧中的亮段范围：

- f00 至 f12：亮段 y 0–580（整条贯通）
- f15：亮段 y 128–580（上端 128 px 变暗）

长度基本不随内容推进而单调变化，只在末帧出现一次变化。
因此它**不是**滚动进度指示器（若是指示器，亮段长度应随进度连续增减），
而是一条固定的版式分割线；末帧的变化属于转场。

这一点修正了此前「5 px 进度条」的判断。

## 四、右侧：数据可视化区（当前素材不可用）

x 1104–1280 在所有采样帧中亮度均值 0.0、最大值 0，即纯黑。
结合此前对同一视频其他时间点的观察，右侧原本是点云球体与环形高亮，
但本批采样帧恰好落在画面切换的黑场或该区域未渲染的时段。

**结论：这批帧无法支撑对右侧可视化实现方式的判断。**
不做推测，也不把它写进借鉴清单。

---

## 五、可借鉴与已借鉴项

| 参考页的做法 | 本作是否采用 | 说明 |
|:---|:---|:---|
| 三栏版面，两侧留黑框住内容 | 部分采用 | 本作是左叙事栏 + 右三维场景的两栏结构。三维场景需要宽度，若再压到中间 72% 会损失可读性；但**左栏宽度固定、右侧独立**这一点一致 |
| 版面骨架固定，只有叙事栏推进 | 已采用 | 本作滚动叙事把叙事步骤 pin 在视口，三维场景始终占满右半，与之一致 |
| 顶部一条横贯的强调带 | 未采用 | 参考页用暖色亮带，本作锁定单一深色主题，加亮带会破坏「数据色只编码数据」的约定 |
| 5 px 竖线分割版式 | 未采用 | 本作靠空间分隔（叙事栏有独立底色与内边距），不额外画线 |
| 内容区持续变化、容器不动 | 已采用 | 与第二条同源 |

### 结论

参考页可借鉴的核心只有一条：**固定版面骨架 + 单栏推进**。
本作已经采用（`src/core/scrollStory.ts` 的 pin 机制 + 右半区常驻三维场景）。

其余视觉特征（暖色顶带、纯黑边距、细分割线）与本作锁定的
「深空冷色 · 数据仪器风」冲突，不引入。
参考页右侧的可视化实现方式因素材不足无法判断，不作推测。

## 六、如何复算

```bash
# 逐帧版面测量（需要 opencv-python）
python - <<'PY'
import cv2, numpy as np
for f in ['f00_0000.png','f08_0521.png','f15_0977.png']:
    im = cv2.imread('docs/ref-video/'+f); g = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)
    print(f, 'left', g[:, :176].mean(), 'rail', g[:, 177:1096].mean(), 'right', g[:, 1104:].mean())
PY
```
